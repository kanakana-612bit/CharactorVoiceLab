# Synthetic Character Sample

This directory contains a wholly synthetic CharacterVoiceDesigner example. It
does not contain a real person's image, voice recording, medical record, or
participant-level research data.

- `20260720-character-voice_Sample.zip` is a loadable project package with
  Stable Diffusion-generated reference images and the resulting design profile.
- `samplevoice.wav` is the corresponding synthesized voice demonstration.

The image-generation prompt, model and VAE identifiers, hashes, and random
seeds embedded in the PNG files are intentionally retained as provenance that
the reference character was generated. Profile measurements and population
settings describe this fictional character and must not be interpreted as
human biometric or clinical data.
